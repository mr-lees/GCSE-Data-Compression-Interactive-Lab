GCSE Exam Tip:

Lossy picture compression (like JPEG) permanently removes extra data. Once you save the compressed file, the lost pixels are gone forever!

Original Picture 256 x 256 pixels
Compressed Picture Quality: 100%

What is happening here?

At 100% quality, every pixel is kept. As you lower the quality slider, the computer starts deleting tiny background details and grouping similar colors together. This makes the file size much smaller!

How MP3 Files Save Space:

1. Removing Super High Pitches Human ears can't hear super high frequencies. MP3 removes these frequencies completely to save space.
2. Deleting Masked Sounds If a loud drum plays at the exact same time as a quiet guitar, your brain can only hear the drum. MP3 deletes the hidden guitar sound!
Lossless Method

Run-Length Encoding (RLE)

RLE groups repeated characters or pixels together into count pairs without losing any data at all!

Text RLE Encoder

Compressed Result:
5A3B2C1D4A

Click squares to toggle between Black (B) and White (W) pixels.

File Size Comparison

Original Size 15 Bytes (1 byte per letter)
RLE Compressed Size 10 Bytes (Count + Letter pairs)
Space Saved: 33.3%

Warning: RLE Made the File Bigger!

When characters don't repeat (like "ABCDEFGH"), storing counts actually doubles the file size from 8 bytes to 16 bytes! RLE only works well when data repeats a lot.

Key Facts About RLE:

  • Lossless: Zero data is lost. You can recreate the exact original text or image.
  • How it works: Replaces repeated items with a count and the item (e.g., 5 'A's becomes "5A").
  • Best for: Simple diagrams, black-and-white logos, or text with lots of repeated spaces.
  • Worst for: Normal text or photos where neighboring pixels or letters keep changing.

Lossless Technique

Run-Length Encoding (RLE)

RLE looks for repeating patterns and replaces them with a number and the item: [Count, Item].

Original: "AAAAABBCC" (9 letters)
RLE: "5A2B2C" (6 characters)
